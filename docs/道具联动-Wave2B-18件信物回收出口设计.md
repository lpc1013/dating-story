# 道具联动 · Wave 2B —— 18 件现有信物回收出口设计

> 配套：Wave1 总纲（`道具联动-Wave1-总纲与海螺.md`）、Wave2A 落地稿（`道具联动-Wave2A-海螺定稿与掉落物剧情化.md`）。
> 本稿只设计**回收出口**，18 件信物已在 `js/backpack.js` 的 `ITEMS` 注册、已有 `reward` 获取点，本稿不重复设计获取。

## 1. 设计机制（与 Wave2A 一致）

- **统一采用「伏笔回收」**：每件信物在**获取点同一条天气变体线**的后续零挂点事件，追加一个 `requireItem:"<id>"` 门控选项（**不消耗**，让信物跟到结局）。
- 理由：① `requireItem` 引擎已在 Wave2A 前修复并 E2E 自证（T2），机制最稳；② 同线闭环确保单周目玩家"拿到即见专属选项"，彻底消除闲置；③ 与 Wave2A 8 件（candy/flower/sticker/shell/clover/origami/ribbon/key）风格统一。
- **关于赠予共鸣（useItem 消耗）与结局信物**：列为 **Wave3 升级项**（见 §6），本轮不落地，避免消耗后无法结局回响的副作用。
