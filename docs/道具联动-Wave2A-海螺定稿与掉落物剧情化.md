## 0. 总体前提与推断（先读，影响全稿）

1. **海螺线归属推断为 `cloudy2`（雾天线）。** 理由：用户拍板「海滨」，而「迷路走到海滨公园」是创意甲（雾天线）的标志性场景；台风线 `rainy2` 以囤货 / 停电 / 烛影 / 新闻直播等室内戏为主，没有海滨场景。故获取点落在 `cloudy2 / 雾中迷路`，回收点两候选均在 `cloudy2` 内。**这是推断非原话**，第 1.4 节给出「若改走台风线」的改动清单，用户随时可反悔。
2. **全部 8 件掉落物升格为剧情信物，废除随机掉落。** 原 `js/gift.js` 的 `triggerRandomDrop` 掉落池清空，8 件全部由剧情选项获取（详见第 2、3 节与落地映射表）。商店货（`js/shop.js` 六件）不升格，本轮不动。
3. **每件都有回收出口。** 采用「伏笔回收（`requireItem`）」为主机制——8 件全部在**同一条天气线内的后续事件**被再次提起，玩家只要拿着就能看到专属选项，**彻底消除「闲置」**。无一件仅靠成就/结局回声兜底。
4. **图标冲突已规避**：原掉落物 `key`（心之钥匙）的 🔑 与 `backpack.js` 既有 `keychain`（猫咪钥匙扣）的 🔑 撞车，本稿将心之钥匙图标改为 **🗝️**。海螺由「精致贝壳」改名为「海螺」🐚（贴耳听声需螺非贝）。

## 2. 其余 7 件掉落物剧情化（各 2 版）

> 统一规则：
> - **获取点**写 `reward: "<id>"`，均落在实读「当前零 reward」事件，不与该事件既有 `reward` 撞车。
> - **回收出口**写 `requireItem: "<id>"`（伏笔回收，不消耗），均落在同线后续零 reward 事件。
