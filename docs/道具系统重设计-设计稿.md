### B.3 吉伊小八彩蛋决策说明

- **保留 `chick`（吉伊小八挂件）作唯一彩蛋**，挂在 `骑士与公主`·A。
  - 理由：该事件 prompt 明确写「帆布包上挂着**吉伊小八**的挂件」，选项 A 反馈也写「那枚**吉伊小八**，从此晃在你胸口」——它是整库与「吉伊小八」IP 绑定最紧、且叙事已落地的物件，作彩蛋最自然。
- **`keychain`（猫咪钥匙扣）不属吉伊小八周边**（仅是普通猫咪挂件），故允许保留为可收集道具；但因 `骑士与公主` 已占 1 个道具（彩蛋），`keychain` 依「每事件≤1 道具」原则**从 `骑士与公主`·B 移出**， relocated 到 `谷子与文创`·A（文创店买钥匙扣顺理成章）。`骑士与公主`·B 改为纯文案 flavor（其现有反馈已描写收到钥匙扣，无需删文，仅去掉 `reward`）。
- 其余吉伊小八 / 谷子 / 拼豆（`blindbox`/`blindbox_hidden`/`badge`/`guzi`/`pindou`）全部删除，符合「仅留 1 个吉伊小八彩蛋」。

## C. 双道具事件拆分方案

### C.1 骑士与公主（sunny2）
- 现状：A=`chick`、B=`keychain`（两处 reward，违例）。
- 处理：
  - **A=`chick` 保留**（吉伊小八彩蛋，唯一）。
  - **B=`keychain` 移出为纯文案 flavor**：删除 B 的 `reward:"keychain"`，其现有反馈文案（"你顺手把它系在自己包上…护身符"）保留作为 flavor，不再发放道具。
  - `keychain` 道具 relocated 到 `谷子与文创`·A（见 C.2）。

## F. 成就变更 spec

### F.1 新增「集齐所有照片」成就

```js
{
  id: 'photo_archive',
  title: '时光集锦',
  description: '集齐相册里的每一张回忆',
  icon: '📔',
  rarity: 'legendary',
  condition: (state) => (state.unlockedPhotos || []).length >= 24,
  progress: (state) => ({ current: (state.unlockedPhotos || []).length, max: 24 })
}
```
- `N = 24`：现有 22 张 + 本稿新增 2 张（`foggy_ruin`、`typhoon_eye`）。
- 由 `checkStatsAchievements` 每轮统一评估（带 `condition` 的成就已在该函数内遍历），无需额外接线。
- `progress` 用于成就面板显示 `current/max`。

### F.2 master_photographer（摄影大师）
- 现状：`收集5张以上的约会照片`，`legendary`。
- 建议：**保留不变**。阈值 5 张极易达成（多数照片由条件 / 事件自然解锁），作为早期引导型传奇成就合理，不与 `photo_archive`（满集）冲突。

### F.3 欧皇附体
- 现状：`description:'一发入魂抽中隐藏款'`，`isEvent:true`，由 `抽奖奇遇`·C 的 `achievement` 数组触发。
- 问题：原绑定对象 `blindbox_hidden`（隐藏款盲盒）已被本设计删除，原描述失效。
- 方案：**保留成就 id / title / icon / rarity / isEvent 不变**（避免清空已解锁记录），仅改描述并确认触发点：
  - `description` 改为 `'在抽奖奇遇中好运爆棚，抽中心仪限定款'`。
  - 触发点不变：`抽奖奇遇`·C 仍带 `achievement:["幸运之神眷顾","欧皇附体"]`，且 C 现发放稀有掉落 `limited_postcard`（"限定明信片"），语义自洽。
  - 顺带：`抽奖奇遇`·C 改挂 `photo:"blindbox_photo"`，让 `blindbox_photo`（欧皇时刻）这张原本不可达的照重新可达。

### F.4 collector（收藏家）
- 现状：`跨周目收集 distinct 道具 ≥ 9`，`legendary`。
- 核对新阵容：全库 **18 个 distinct 道具**。单条天气线最多获得 4 个（sunny2：充电宝/吉伊小八挂件/猫咪钥匙扣/限定明信片），其余线 2–3 个；**单线无法达 9**，但跨周目累积 localStorage `collected-items` 后，约 3 条不同天气线（如 sunny2=4 + sunny=3 + snowy=3 = 10）即可稳定 ≥9。
- 结论：**阈值 9 保留**。该成就本就是跨周目收集向，单线不达预期内；无需下调。若主理人希望降低门槛，可降到 8（仍略高于单线最大 4 的两倍）。

   - **缓解**：扩展静态测试 `(E) 道具引用一致性` 块，使其**同时校验 `choice.photo` 引用是否存在于 `albumPhotos`**（现行 (E) 仅校验 `reward/useItem/requireItem`，见 `docs/道具接入指南.md`）。落地前必跑，FAIL 即修。
